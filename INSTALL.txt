Eventide's Banpilot 설치 안내

가장 간단한 설치: 릴리스의 Banpilot-버전-Setup-x64.exe를 더블클릭합니다.
필요한 파일이 내장되어 있어 직접 압축을 풀 필요가 없습니다.

아래는 ZIP 배포를 선택한 경우의 설치 방법입니다.

1. ZIP 파일을 모두 압축 해제합니다. ZIP 안에서 바로 실행하지 마세요.
2. 압축을 푼 폴더의 Install.bat을 더블클릭합니다.
3. 처음 설치하는 PC에서는 인증서 등록을 위한 관리자 권한 요청이 나타납니다.
4. Installed 메시지가 나오면 설치가 완료된 것입니다.
5. Windows 설정에서 'Copilot 키'를 검색하고 사용자 지정 앱 목록을 엽니다.
6. 다음 중 하나를 선택합니다.
   - Eventide's Banpilot - 아무 동작 안 함
   - Eventide's Banpilot - Windows 키 한 번 누르기

한 번 설치하고 선택하면 매번 Install.bat을 실행할 필요는 없습니다.
키를 누르면 Windows가 선택한 앱을 실행하고, 앱은 동작 후 종료합니다.

대상: Copilot 키 앱 사용자 지정을 지원하는 Windows 11 x64.
Windows 키 모드는 원래 키에서 손을 뗀 뒤 RWindows를 한 번 누릅니다.
누르는 동안 Windows 수정 키를 유지하는 기능은 아닙니다.

이 배포는 자체 서명된 테스트 인증서를 사용합니다.
설치기는 공개 인증서를 LocalMachine\TrustedPeople에 등록합니다.
상용 인증서의 평판을 갖춘 설치 파일이 아니므로 Windows가 경고할 수 있습니다.
조직 정책으로 설치가 차단된 PC에서는 해당 정책을 따라야 합니다.
개인 키는 배포 파일에 포함하지 않습니다.

오류가 나면 창에 남아 있는 오류 메시지를 확인하세요.
제거 및 인증서 정리는 README.md의 '제거 및 복구'를 참고하세요.
